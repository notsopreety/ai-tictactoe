# AI Tic Tac Toe 🎮

A modern, intelligent Tic Tac Toe game featuring a trash-talking AI opponent with dynamic commentary and voice synthesis. Built with HTML5, CSS3, and JavaScript.

![Game Preview](preview.png)

## 🌟 Features

- 🤖 Intelligent AI opponent with multiple difficulty levels
- 💬 Dynamic, personality-driven AI commentary
- 🗣️ Voice synthesis for AI responses
- 🎨 Modern, responsive UI with glassmorphism effects
- ✨ Smooth animations and transitions
- 📱 Mobile-friendly design
- 🏆 Score tracking system

## 🎯 Difficulty Levels

- **Casual**: Perfect for beginners
- **Serious**: Balanced challenge
- **Ruthless**: Maximum difficulty

## 🚀 Getting Started

### Prerequisites

- PHP server (like XAMPP, WAMP, or any web server with PHP support)
- Modern web browser (Chrome, Firefox, Safari, Edge)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/notsopreety/ai-tictactoe.git
```

2. Move the files to your web server directory

3. Start your PHP server

4. Access the game through your web browser:
```
http://localhost/tictactoe
```

## 🎮 How to Play

1. Choose your preferred AI difficulty level
2. Click any empty cell to make your move
3. Try to get three in a row while blocking the AI
4. Toggle AI voice with the speaker button
5. Start a new game anytime with the "New Game" button

## 🛠️ Technologies Used

- HTML5
- CSS3 with Animate.css
- Vanilla JavaScript
- PHP (for API proxy)
- Web Speech API
- GPT-powered AI responses
